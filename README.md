# IshGarant

**IshGarant** — это MVP escrow-платформа для безопасных сделок между заказчиками и исполнителями в сфере строительства и бытовых услуг в Узбекистане.

Проект решает проблему недоверия между сторонами: заказчики боятся предоплаты без гарантии результата, а исполнители — выполнения работы без оплаты. IshGarant выступает гарантом сделки, удерживая средства до подтверждения выполнения работ.

🌐 Демо-версия: https://ishgarant.netlify.app/

---

## 🚀 О проекте

В Узбекистане значительная часть строительных и ремонтных услуг осуществляется без официальных договоров и гарантий. Это приводит к:

- Потере денег из-за недобросовестных исполнителей
- Неоплате выполненных работ
- Конфликтам и отсутствию механизмов разрешения споров
- Недоверию на рынке услуг

**IshGarant** предлагает безопасную модель работы через escrow-механизм.

---

## 🛡 Как это работает (MVP модель)

1. **Заказчик создаёт заказ**
   - Описание задачи
   - Стоимость
   - Сроки выполнения

2. **Исполнитель принимает заказ**

3. **Заказчик вносит оплату**
   - Деньги замораживаются на платформе
   - Исполнитель видит подтверждение оплаты

4. **Исполнитель выполняет работу**

5. **Подтверждение выполнения**
   - Заказчик подтверждает выполнение
   - Средства переводятся исполнителю

6. **В случае спора**
   - Платформа выступает посредником
   - Принимается решение о возврате или выплате
